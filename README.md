# ROSE — закрытый клуб ужинов на шестерых

> Сначала разговор. Потом взгляд.

ROSE — концепт премиального клуба знакомств для Москвы. Алгоритм вместе с матчмейкером сажает за один стол в ресторане трёх мужчин и трёх женщин, которым будет легко говорить друг с другом. Фотографий людей в клубе нет. Утром после ужина каждый тайно дарит розу тем, кого хочет увидеть снова. Контакты открываются только при взаимной розе.

## Механика

- **Стол 3 + 3.** Все без пары, у всех одна цель. Подбор по стилю общения, роли в компании, ценностям и интересам.
- **Афиша столов.** Свайпают не людей, а вечера: литературный ужин, кино и вино, джаз, галерея, шеф-стол, игры, бранч, природа.
- **Вечер без фото.** До ужина видны только имя, возраст, знак ✓ и один общий интерес.
- **Тайная роза.** Окно 24 часа. Роза, дружба или «пропустить». Невзаимную розу никто не увидит.
- **Матчмейкер.** Интервью при вступлении, калибровка на первых трёх ужинах, оценка каждого вечера по шкале 1–4.

## Как открыть

- Онлайн — по ссылке на GitHub Pages.
- Локально — скачайте репозиторий и откройте `index.html` в браузере. Шрифты подгружаются из Google Fonts; без интернета прототип работает со системными шрифтами.

## Фирменный стиль коротко

| Токен | Цвет | Где |
|---|---|---|
| Noir | `#000000` | Фон |
| Velvet | `#151313` | Поверхности |
| Bone | `#F2ECE6` | Текст |
| Rose | `#E3122F` | Акцент, кнопки |
| Leaf | `#3E8E4A` | Только знак ✓ |

Шрифты: **Cormorant Garamond** (заголовки) и **Onest** (интерфейс), оба под лицензией OFL. Для афиш дополнительно Playfair Display, Unbounded, Oswald и Lobster (OFL).
